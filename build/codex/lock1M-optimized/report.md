通过 ST-Link 连续运行热连接读取 32 组快照，时间 10:05:08.979 至 10:05:24.132。采样块号 64,051 至 93,648，有效处理块数同步增加了 29,597，末次累计处理 93,649。32 组快照均显示信号有效、调节生效、无饱和。整周滑移、参考块错配、ADC 错误和 DAC 欠载累计均为 0。内部相位误差 −0.00691° 至 +0.00554°，快照均方根 0.00350°。环路给 NCO 的频率命令 20000.60991 至 20000.61291 Hz。测量参考为软件 NCO；模拟引脚间相位需由外部仪器测量。复位至首次采样期间的锁定时间未测量。

构建 Debug 与 Release 通过，均无新增警告。主机测试涵盖软件/CMSIS 替身鉴相、原版七个 App 场景及 1× 逐码对照。原 H7 的 PI 饱和与 500 Hz 低频测试假设调节范围 ±100 Hz，而当前固件默认 ±1000 Hz；两项原样运行失败，在测试夹具中显式指定 ±100 Hz 后通过。量产代码参数未因测试改变。

Release ELF 大小 92,504 B，Flash 占用 40,928 B，RAM 占用 50,784 B。VFPv4-D16，硬浮点传参。.bss 最大对象为 output_samples 与 dac_ring 各 16,384 B、nco_waveform_lut 12,296 B。
